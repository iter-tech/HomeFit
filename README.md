# Домашня форма

Адаптивний план домашніх тренувань: 2 на тиждень, без обладнання (стілець, стіл, підлога).
Акцент: спина, стегна (коліно), скутість, жироспалювання без стрибків.

## Як працює
- Тест на старті → стартовий рівень кожної вправи.
- Тренування A і B чергуються. Кожна вправа має 3–5 рівнів складності.
- Після кожного підходу вписуєш, скільки зробив. Всі підходи на цілі → ціль +1. Всі на максимумі → новий рівень. Не дотягнув сильно → ціль −1. «Було боляче» → легший варіант.
- Перед тренуванням оцінка болю спини і коліна. 6+ → легке тренування (теж рахується).
- Кожен 6-й тиждень — розвантажувальний (2 підходи замість 3).
- Тиждень Пн–Нд, потрібно 2 тренування. Банер попереджає, коли днів залишається мало.
- Селфі після тренування, вага і талія, історія, резервна копія.
- Дані зберігаються лише в браузері телефона. Раз на місяць: Налаштування → «Зберегти копію».

## Публікація на GitHub Pages
1. Відкрити https://github.com/new
2. Repository name: `homefit`, вибрати Public, натиснути Create repository.
3. На сторінці репозиторію натиснути «uploading an existing file».
4. Перетягнути 7 файлів: index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png, README.md. Натиснути Commit changes.
5. Відкрити https://github.com/ВАШ_ЛОГІН/homefit/settings/pages
6. Source: Deploy from a branch. Branch: main, папка / (root). Save.
7. Через 1–2 хв відкрити https://ВАШ_ЛОГІН.github.io/homefit/
8. iPhone (Safari): Поділитися → «На екран „Додому“». Android (Chrome): ⋮ → «Встановити додаток».
